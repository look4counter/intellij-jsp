# 기능 명세: JSP 파일 아이콘

**작성일**: 2026-10-20
**상태**: 검토 완료
**입력**: JSP 파일에 IntelliJ에서 제공하는 기본 JSP 아이콘을 사용한다.

## 사용자 시나리오와 검증

### 사용자 이야기 1 — JSP 파일 식별 (우선순위: P1)

개발자는 프로젝트 트리와 에디터 탭에서 JSP 파일을 일반 텍스트 파일과 구분한다.
우선 이유: 파일 종류를 빠르게 식별하는 것이 요청의 목적이다.
독립 검증: 등록된 JSP 파일 유형이 IntelliJ 기본 JSP 아이콘을 반환하는지 확인한다.

1. 프로젝트에서 JSP 파일을 찾으면 IntelliJ 기본 JSP 아이콘으로 표시한다.
2. JSP 파일을 열면 같은 아이콘을 탭에서 사용한다.
3. 테마와 화면 배율에 따른 표시를 IntelliJ 기본 아이콘 처리에 맡긴다.

### 경계 사례

- 작은 크기 및 고해상도 화면에서 윤곽을 유지한다.
- 파일을 열기 전에도 아이콘 리소스를 로드할 수 있어야 한다.

## 요구사항

- **FR-001**: JSP 파일 유형에 IntelliJ 기본 JSP 아이콘을 사용해야 한다.
- **FR-002**: 테마와 배율 처리는 플랫폼 기본 동작을 따라야 한다.
- **FR-003**: 자체 제작 JSP 아이콘 리소스를 제거하고 파일 연결 및 편집 기능을 유지해야 한다.

## 성공 기준

- **SC-001**: 파일 유형이 플랫폼 기본 JSP 아이콘을 직접 반환한다.
- **SC-002**: 자체 제작 JSP 아이콘 두 개가 소스와 배포물에 남지 않는다.
- **SC-003**: 플러그인 빌드와 설정 검증에 실패가 없다.

## 가정과 범위

기존 파일 유형 등록을 이용하며 플러그인 로고는 변경하지 않는다. 플랫폼이 기본 JSP 아이콘을 제공하므로 별도 이미지 파일을 추가하지 않는다.
