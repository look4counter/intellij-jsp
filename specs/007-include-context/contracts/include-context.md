# include 문맥 계약

- `<%@ include file="..." %>`와 작은따옴표 속성을 지원한다.
- 포함 지시자를 만난 위치에서 대상의 정적 include를 재귀적으로 펼친다.
- import와 선언은 번역 단위 전체에서 보이며 지역 변수는 삽입 순서와 Java 범위를 따른다.
- 유일한 부모 경로는 조각 편집에도 적용한다. 여러 부모·반복 삽입·순환으로 모호하면 자체 문맥을 사용한다.
- jsp와 jspf를 같은 파일 유형으로 편집한다.
- 누락·미완성·동적 include와 JSP 주석은 가상 Java 코드를 추가하지 않는다.
- 완성·포매팅은 현재 파일만 바꾸며 가상 include 원문은 기록하지 않는다.
- 웹 루트 선택 및 깊이·확장·문자 수 제한은 구현 계획을 따른다.
