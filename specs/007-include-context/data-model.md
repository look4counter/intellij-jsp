# 데이터 모델

## 지시자와 포함 관계

지시자는 종류와 따옴표로 구분된 속성을 가진다. 포함 관계는 부모 파일, 지시자 위치와 대상 파일을 가진다. 누락되거나 미완성인 경로는 대상 없음으로 처리한다.

## 자바 조각과 번역 단위

자바 조각은 원본 파일, 원본 시작 위치, 종류, 본문을 가진다. 번역 단위는 순서 있는 조각들과 중복을 제거한 import 집합이다. 선언은 클래스 본문에, 실행과 표현식은 메서드 본문에 배치한다.

## 편집 문맥

현재 파일과 선택된 최상위 부모, 실제 호스트 목록을 가진다. 현재 파일이 펼친 번역 단위에 정확히 한 번 등장할 때만 부모 문맥을 사용한다. 역그래프는 의존성 변경 시 폐기한다.
