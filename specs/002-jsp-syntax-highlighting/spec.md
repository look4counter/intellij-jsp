# 기능 명세: JSP 혼합 구문 강조

**작성일**: 2026-10-19
**상태**: 명세 확정
**기능 브랜치**: 없음(현재 폴더는 Git 저장소가 아님)
**입력**: JSP에서 기존 HTML·JavaScript·CSS 강조 기능을 재사용한다.

## 사용자 시나리오와 검증

### 사용자 이야기 1: HTML과 JSP 구분 (우선순위 P1)

개발자는 JSP 파일에서 HTML 태그·속성·문자열·주석과 JSP 전용 구문을 색으로 구분한다.
우선 이유: 기본 JSP 편집 가독성을 제공한다.
독립 검증: HTML과 JSP 지시자·스크립틀릿·표현식·선언·주석·EL이 섞인 파일의 강조 구간을 확인한다.

1. JSP를 열면 HTML 영역은 IDE의 HTML 색상 설정을 따른다.
2. `<%@ %>`, `<% %>`, `<%= %>`, `<%! %>`, `<%-- --%>`, `${…}`, `#{…}`를 HTML과 구분한다.
3. HTML 속성에 삽입한 JSP 표현식 앞뒤의 속성 강조가 유지된다.

### 사용자 이야기 2: 내장 웹 언어 강조 (우선순위 P2)

개발자는 JSP의 `<script>`와 `<style>` 내부를 기존 JS·CSS 색상으로 읽는다.
우선 이유: 한 파일의 혼합 언어를 이해하기 쉽다.
독립 검증: 각 언어 지원이 활성화된 환경에서 같은 코드의 독립 HTML 파일과 JSP 파일의 강조를 비교한다.

1. 사용 가능한 JS 지원이 있으면 `<script>` 내용은 해당 강조 기능을 사용한다.
2. 사용 가능한 CSS 지원이 있으면 `<style>` 내용은 해당 강조 기능을 사용한다.
3. JS 문자열과 CSS 값에 JSP가 들어가도 JSP 이후 웹 언어 강조가 복원된다.
4. JS·CSS 지원이 없어도 플러그인은 로드되고 HTML·JSP 강조와 편집이 가능하다.

### 경계 조건

- 빈 파일, 닫히지 않은 JSP 블록·주석·EL에서도 멈추거나 예외를 내지 않는다.
- EL의 중첩 중괄호와 문자열 안의 중괄호를 처리한다.
- 편집 도중 구분자를 추가·삭제하면 현재 내용에 맞게 강조를 갱신한다.
- JSP 주석 내부의 가짜 HTML·script·style 태그가 뒤의 강조 상태를 바꾸지 않는다.
- JSP 파일 연결과 원문·인코딩·저장 동작을 유지한다.

## 요구사항

- **FR-001**: HTML 영역은 기존 HTML 강조 기능과 색상 설정을 재사용해야 한다.
- **FR-002**: JSP 블록 종류, 주석, EL을 식별하고 HTML과 구분해 강조해야 한다.
- **FR-003**: 사용 가능한 기존 JS·CSS 지원으로 script·style 내부를 강조해야 한다.
- **FR-004**: JS·CSS 지원이 없어도 HTML·JSP 강조와 편집을 제공해야 한다.
- **FR-005**: JSP가 속성·JS 문자열·CSS 값에 삽입되어도 주변 언어의 문맥을 보존해야 한다.
- **FR-006**: 미완성 구문과 편집 중 구분자 변경을 안전하게 처리해야 한다.
- **FR-007**: 기존 파일 열기·편집·저장과 IDE 테마의 색상 설정을 유지해야 한다.

### 주요 개체

- JSP 영역: 종류, 시작·끝 위치, 완성 여부를 가진 텍스트 구간.
- 호스트 영역: JSP를 제외한 HTML 및 내부 웹 언어 구간.

## 성공 기준

- **SC-001**: HTML·JSP·JS·CSS 대표 예제 4종에서 지정한 강조 구간이 기대 언어와 일치한다.
- **SC-002**: 미완성 구문과 구분자 편집 사례에서 예외 없이 현재 텍스트 전체를 빠짐없이 강조한다.
- **SC-003**: 웹 언어 지원이 없는 환경에서도 HTML·JSP 편집이 가능하다.
- **SC-004**: JSP의 원문이 구문 강조 과정에서 변경되지 않는다.

- 기존 IntelliJ IDEA 2025.3.6.1 대상을 유지한다. JS·CSS 재사용 여부는 설치·활성화된 기능에 따른다.
- 구문 강조를 제공하며 자동 완성·구문 오류 검사·리팩터링·JSP 실행과 Java 의미 분석은 범위 밖이다.
- JSP 블록 본문은 기본 JSP 색상을 적용한다. Java 구문 강조는 후속 범위이다.
- 경계와 편집 갱신 및 실제 HTML 강조 연동은 자동 검증한다. UI 수동 검증 수행 여부를 기록한다.
