# 데이터 모델

- JSP 토큰: 종류, 시작 위치, 끝 위치를 갖는다. 구간은 겹치지 않고 원문의 모든 문자를 덮는다.
- HTML_TEXT: JSP를 제외한 호스트 조각이다. HTML 레이어에 순서대로 전달한다.
- JSP 종류: 지시자, 스크립틀릿, 표현식, 선언, 주석, EL.
- 재시작: 각 토큰 경계는 독립적으로 다시 읽을 수 있다. 미완성 JSP는 입력 끝까지 하나의 토큰이다.
- 강조 키: JSP 종류별 키는 IDE 기본 색상 키를 대체값으로 갖는다.
- 강조 결과는 문서에 저장하지 않는다. 테마와 문서 변경 시 IDE의 강조 체계로 다시 계산한다.
