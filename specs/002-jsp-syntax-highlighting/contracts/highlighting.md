# 구문 강조 계약

- Community JSP 파일 유형과 jsp 확장자 연결을 유지한다.
- editorHighlighterProvider는 JSP 토큰 강조와 HTML 레이어를 함께 제공한다.
- HTML 조각은 JSP 영역을 제외하고 빈 구분자로 연결한다.
- JSP 주석은 --%>, 나머지 퍼센트 블록은 %>에서 끝난다.
- EL은 중괄호 깊이와 인용 문자열을 구분하며 이스케이프된 EL 시작은 호스트 텍스트로 남긴다.
- 미완성 영역은 입력 끝까지 처리하며 0 길이 토큰을 만들지 않는다.
- HTML·JS·CSS 색상은 기존 제공자를 따르고 JSP 종류별 색상은 IDE 기본 테마 값을 대체값으로 사용한다.
- 웹 언어 제공자가 없으면 해당 호스트 구간은 HTML 기본 처리로 남는다. 편집 기능은 유지한다.
- 자동 완성, PSI 구문 분석과 Java 본문 내부의 세부 강조는 제공하지 않는다.
