# 연구: 지시자 Enter

- 연구 에이전트가 로컬 SDK 바이트코드를 확인했다. TemplateLanguageBlock에는 별도 getChildAttributes 재정의가 없고 AbstractBlock의 자식 indent 기본값은 null이다. 8칸 상수는 플러그인에 없다.
- 지시자는 Java 주입 호스트가 아니므로 가상 Java 클래스·메서드가 직접 원인이라는 초기 추정은 해당 재현 코드에 적용되지 않는다.
- 결정: 좁은 EnterHandlerDelegate를 사용한다. formatter 전체의 자식 들여쓰기를 바꾸면 HTML 블록 계산에 영향을 줄 수 있어 제외한다.
- 실제 Enter 액션으로 수정 전 재현 및 수정 후 결과를 확인한다.

## 수정 전 관찰

로컬 261 SDK의 기본 설정에서는 사용자 예시의 실제 공백 8칸 현상이 재현되지 않았다. 비물리·물리 JSP에서 문서 내용과 커서 논리 열을 모두 확인했으며 최상위 다음 줄은 0열이었다. 따라서 사용자 환경의 정확한 발생 원인은 미확정이다. 구현은 일반적인 원인 단정 대신 지시자 경계에서 기존 들여쓰기만 복제하고 기본 후속 계산을 중단하는 명시적 정책을 제공한다.
