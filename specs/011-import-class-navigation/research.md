# 연구: import 참조 탐색

- 결정: JspDirective의 범위별 PsiReferenceBase로 구현한다. 기존 include 참조와 실제 GotoDeclarationAction 테스트 구조를 연구 에이전트가 읽기 검토했다. 기존 선언 이동 핸들러는 지시자에서 기본 참조 탐색을 허용하므로 수정하지 않는다.
- 결정: JavaPsiFacade.findClass와 원래 해석 범위를 사용한다. 프로젝트 클래스·라이브러리·중첩 클래스 탐색을 재구현하지 않는다.
- 결정: 속성 목록을 추가로 유지해 같은 지시자의 반복 import도 지원한다. 기존 맵 소비자는 계속 마지막 속성 값을 사용하므로 기존 동작은 유지된다.
- 결정: 이름 범위만 참조로 제공하고 와일드카드는 생략한다. 패키지나 임의 클래스에 연결하지 않는다.
