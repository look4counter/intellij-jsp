# 편집 계약

1. 지시자 구분자·이름·속성·등호·문자열은 독립된 테마 색상 역할을 사용한다.
2. 강조는 원문과 PSI를 수정하지 않으며 미완성 지시자가 다음 지시자의 색상 상태를 오염시키지 않는다.
3. 기존 이름·속성·고정값 완성을 유지하고 import 클래스·패키지 및 include 파일·폴더를 제공한다.
4. 선택은 현재 항목만 바꾸며 앞선 목록·경로·기존 따옴표와 주변 문서를 보존한다.
5. 지시자 구분 문자와 속성 선택 뒤 자동 팝업을 제공하며 다른 언어에는 지시자 후보를 제공하지 않는다.
6. 인덱싱 중 클래스 검색을 생략하되 색상과 고정값 완성은 유지한다.
