# 기능 명세: 지시자 세부 색상과 자동완성

**작성일**: 2026-10-20
**상태**: 명세 검증 완료
**입력**: 세부 색상을 적용하고 자동완성도 적용한다.

## 사용자 시나리오와 검증

### 사용자 이야기 1 — 지시자 내부 구분 (우선순위 P1)

개발자는 JSP 지시자의 시작·끝 구분자, page·include·taglib 이름, 속성 이름, 등호, 따옴표와 문자열 값을 구분한다.
독립 검증: 같은 지시자의 각 위치가 의도한 색상 역할에 연결되는지 확인한다.

1. 큰따옴표·작은따옴표·여러 줄·미완성 지시자에서도 세부 강조를 제공한다.
2. 테마의 기본 색상 역할을 따르며 기존 HTML·Java·주석·EL 강조는 유지한다.
3. 편집 후 강조가 갱신되며 원문과 PSI·탐색을 바꾸지 않는다.

### 사용자 이야기 2 — 지시자 입력 완성 (우선순위 P1)

개발자는 지시자 이름·속성·대표 값을 완성하고 import 클래스와 include 파일 경로도 선택한다.
독립 검증: 실제 완성 후보 선택 후 주변 원문과 커서를 확인한다.

1. 기존 page·include·taglib 이름·속성·고정값 완성을 유지한다.
2. page import에서 프로젝트·등록 라이브러리 클래스와 패키지를 완성한다. 쉼표 목록에서는 현재 항목만 변경한다.
3. include file에서 현재 파일 기준 상대 경로·상위 폴더·웹 루트 경로의 파일과 폴더를 완성한다.
4. 따옴표·점·쉼표·슬래시 같은 지시자 입력에서도 완성창을 호출할 수 있다. Ctrl+Space도 유지한다.
5. 기존 따옴표·앞선 항목·접미사·다른 속성과 주변 원문을 보존한다.

## 요구사항

- **FR-001**: 지시자 구분자·이름·속성·등호·문자열의 세부 색상 역할을 제공한다.
- **FR-002**: 미완성·여러 줄·반복 지시자·증분 편집에서 텍스트 전체를 빠짐없이 강조하고 기존 언어 강조·테마를 유지한다.
- **FR-003**: 지시자 이름·속성·고정값 완성과 중복 속성 제외 정책을 유지한다.
- **FR-004**: page import의 현재 목록 항목에 프로젝트 해석 범위의 클래스·패키지 완성을 제공한다.
- **FR-005**: include file의 상대·상위·웹 루트 경로에 실제 파일·폴더 완성을 제공한다.
- **FR-006**: 지시자 문맥에서 구분 문자 입력의 완성창 호출을 지원하고 다른 언어·문자열·JSP 주석에 지시자 후보를 섞지 않는다.
- **FR-007**: 선택 시 현재 입력 구간과 커서를 올바르게 처리하고 따옴표·목록·접미사·주변 문서를 보존한다.
- **FR-008**: 인덱싱 중 색상과 고정 완성을 유지하며 클래스 검색은 생략한다. 기존 Enter·탐색·자동 import·포매팅 및 전체 검증과 배포 빌드를 통과한다.

## 성공 기준

- **SC-001**: 지시자의 각 의미 구간이 독립된 색상 키로 표시되고 편집·테마 검증에서 누락 구간이 없다.
- **SC-002**: 이름·속성·import·include 후보 선택 시 목표 입력을 완료하고 의도하지 않은 문서 변경이 0건이다.
- **SC-003**: 신규 및 기존 자동 검증과 배포 빌드가 통과한다.

## 가정과 범위

직전 대화에서 언급한 지시자 내부를 대상으로 한다. Java 본문은 기존 Java 강조·완성을 사용하고 EL 내부 세분화·JSTL/TLD 태그 완성은 제외한다. 색상은 테마 기본 역할을 재사용하며 별도 색상 설정 화면은 추가하지 않는다. include 완성은 경로 후보를 제공하며 파일 생성·이동은 하지 않는다.

## 명확화 검토

speckit-clarify로 대상·입력 흐름·경계·의존성과 완료 조건을 검토했다. 기존에 부족했던 지시자 내부 색상과 클래스·경로 값 완성을 보완하는 범위로 확정했으며 추가 질문은 없다.
