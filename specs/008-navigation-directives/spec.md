# 기능 명세: JSP 선언 이동과 지시자 완성

**작성일**: 2026-10-20
**상태**: 검토 완료
**입력**: include 파일과 포함된 함수의 Ctrl+클릭 이동, JSP 지시자 자동완성을 제공한다.

## 사용자 시나리오와 검증

### 사용자 이야기 1 — include 파일 열기 (우선순위: P1)

개발자는 정적 include의 file 속성을 Ctrl+클릭하거나 선언 이동 단축키로 연다.
우선 이유: 경로가 맞는지 확인하고 조각을 바로 편집해야 한다.
독립 검증: 상대·상위·웹 루트 경로의 이동 대상 파일을 확인한다.

1. 따옴표 안 경로에서 대상 JSP 또는 JSPF 파일로 이동한다.
2. 없는 경로와 미완성 속성은 예외와 잘못된 이동을 만들지 않는다.

### 사용자 이야기 2 — 포함 함수 선언으로 이동 (우선순위: P1)

개발자는 포함된 함수 호출을 Ctrl+클릭해 가상 코드 대신 실제 선언 위치로 이동한다.
우선 이유: 현재 Java 문맥은 완성을 제공하지만 선언 위치 연결이 부족하다.
독립 검증: include.jsp의 test 호출에서 해당 파일의 test 식별자 위치가 이동 대상으로 반환된다.

1. 직접·중첩 include와 같은 파일의 함수 호출을 실제 선언으로 연결한다.
2. 오버로드는 Java가 해석한 선언으로 이동한다.
3. include 또는 선언 편집 후 이동 대상을 갱신한다.
4. 일반 Java 라이브러리 함수의 기존 이동과 모호한 부모의 자체 문맥 정책을 유지한다.

### 사용자 이야기 3 — JSP 지시자 작성 (우선순위: P1)

개발자는 지시자 이름·속성·대표적인 고정 값을 완성한다.
우선 이유: 문법을 외우지 않고 유효한 JSP 지시자를 작성해야 한다.
독립 검증: page·include·taglib의 이름과 속성, boolean·인코딩 등의 값을 완성하고 삽입 결과를 확인한다.

1. `<%@` 다음에 page, include, taglib를 제안한다.
2. 이름에 맞는 속성을 제안하고 선택하면 필요한 등호·따옴표와 입력 위치를 제공한다.
3. 이미 작성한 속성은 중복 제안하지 않는다. 반복 가능한 page import는 허용한다.
4. 완성은 주변 HTML·Java·JSP 주석을 변경하지 않고 지시자 밖에는 후보를 노출하지 않는다.

### 경계 사례

- 작은따옴표·큰따옴표, 한글과 공백, 미완성 지시자, 이미 존재하는 등호·따옴표를 처리한다.
- 누락 파일과 해석되지 않는 함수는 가상 파일이나 엉뚱한 위치로 강제 이동하지 않는다.
- 파일명과 함수명이 같아도 원본 위치 매핑과 Java 해석 결과로 구분한다.

## 요구사항

- **FR-001**: 정적 include file 값에서 기존 경로 정책에 따라 파일로 이동해야 한다.
- **FR-002**: 포함 함수 호출을 실제 JSP 선언의 식별자 위치로 연결해야 한다.
- **FR-003**: 중첩·오버로드·변경 반영 및 기존 Java 이동 동작을 유지해야 한다.
- **FR-004**: 일반 JSP의 page·include·taglib 이름 및 표준 속성을 완성해야 한다.
- **FR-005**: 대표적인 고정 속성 값과 중복 방지, 등호·따옴표 삽입을 제공해야 한다.
- **FR-006**: 미완성 입력·누락·지시자 밖의 위치를 안전하게 처리하고 원문을 보존해야 한다.
- **FR-007**: 기존 include·완성·강조·포매팅 테스트와 빌드 검증을 유지해야 한다.

### 주요 개체

- 지시자: 종류, 이름 범위, 속성 이름·값·따옴표 범위.
- 소스 연결: 가상 Java 범위와 실제 파일·본문 범위의 대응.
- 이동 대상: 실제 파일과 선언 식별자 위치.

## 성공 기준

- **SC-001**: 경로와 함수 이동 테스트가 실제 파일 및 정확한 선언 오프셋을 반환한다.
- **SC-002**: 세 지시자의 이름·속성·값 완성 및 삽입 검증이 통과한다.
- **SC-003**: 미완성 입력과 지시자 밖의 음성 검증에서 원문 손실과 예외가 없다.
- **SC-004**: 기존 테스트 및 플러그인 빌드·설정 검증에 실패가 없다.

## 가정과 범위

현재 지원하는 jsp·jspf와 정적 include를 대상으로 한다. Ctrl+B도 같은 선언 이동 경로를 사용한다. tag 파일 전용 tag·attribute·variable 지시자, XML JSP, TLD 검색·태그 완성, import 자동 추가, 이름 변경 리팩터링과 include 파일명 완성은 범위 밖이다. 지시자 값 완성은 boolean, language, buffer, pageEncoding, contentType의 대표 값을 제공한다.
