# 데이터 모델

## 지시자 구문

종류, 이름 범위, 속성 목록을 가진다. 속성에는 이름과 값, 값 범위 및 따옴표가 있다. 미완성 입력은 완성 문맥으로 처리한다.

## Java 원본 범위

가상 Java 범위와 원본 VirtualFile, 원본 본문 범위가 일대일 대응한다. 합성 클래스·메서드·표현식 래퍼는 원본 범위가 없다. Java PSI 해석으로 얻은 선언 이름의 범위를 원본 범위로 변환한다.

## 탐색 대상

실제 JSP 파일과 원본 식별자 오프셋, 이름을 가진다. 파일과 범위가 유효할 때 해당 위치로 이동한다.

## 완성 문맥

지시자 이름, 속성 이름 또는 속성 값 상태를 가진다. 접두 문자열과 현재 따옴표, 이미 있는 속성 목록을 사용해 후보와 삽입 동작을 결정한다.
