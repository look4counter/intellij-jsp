# 편집 계약

- include file 경로는 기존 상대·웹 루트 정책으로 해석하여 실제 파일을 반환한다.
- 함수 호출은 Java가 선택한 선언 이름 범위를 실제 원본에 연결한다.
- 플랫폼 핸들러는 원본이 있는 JSP 함수만 처리하고 다른 Java 이동은 위임한다.
- 완성 이름은 page·include·taglib이고 속성은 해당 지시자의 표준 속성이다.
- boolean·language·buffer·pageEncoding·contentType은 대표 값 후보를 제공한다.
- 속성 삽입은 기존 등호와 따옴표를 중복하지 않고 값 입력 위치로 커서를 옮긴다.
- JSP 주석·HTML·Java·EL에는 지시자 후보를 추가하지 않는다.
- 선언 이동과 완성은 다른 문서를 수정하지 않는다.
