# 편집 계약

현재 계약은 기능 철회다. 정리 액션과 Ctrl+O 연결을 제공하지 않고 기존 Java import 자동 추가와 IDE 키맵을 보존한다. 아래 항목은 철회된 이전 계약이다.

1. JSP·JSPF에서 Ctrl+O 또는 액션 검색의 `JSP 미사용 import 정리`로 실행한다.
2. 사용하는 클래스·와일드카드·미해결 클래스와 안전하게 판단할 수 없는 문맥은 유지한다.
3. import 목록의 남은 이름은 원래 순서로 유지한다. 다른 속성·따옴표·본문은 보존한다.
4. 빈 import 속성은 제거하며 다른 속성도 없을 때만 지시자를 제거한다. 주변 줄바꿈은 보존한다.
5. include 관련 다른 파일을 수정하지 않는다. 다중 부모·순환·누락 경로는 제거하지 않는다.
6. 실행 취소 한 번으로 복원하며 연속 실행 결과는 동일하다.
7. 일반 Java·HTML에서는 비활성화하며 읽기 전용·인덱싱 중 변경하지 않는다.
