# 데이터 모델

현재 기능 철회로 아래 정리 전용 데이터는 제거한다. 번역 단위는 기존 parts·imports·currentFile만 유지한다. 아래는 이전 설계 이력이다.

- 번역 단위: 기존 parts·imports·currentFile와 정적 include 해석의 완전성 플래그 및 방문한 파일 집합. Java 본문이 없는 include 파일의 JSP 클래스 속성도 보존 판단에 사용한다.
- 제거 후보: 유효한 명시적 클래스 이름과 모든 주입 파일에서 미사용인지 여부.
- 원문 편집: 시작·끝 오프셋 및 대체 문자열. 문서 변경 시 적용하지 않는다.
- 정리 작업: 분석 당시 문서 수정 번호, 편집 목록과 대상 호스트 파일. 영구 저장하지 않는다.
