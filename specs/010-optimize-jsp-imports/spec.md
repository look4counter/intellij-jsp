# 기능 명세: Ctrl+O import 정리 기능 제거

**작성일**: 2026-10-20
**상태**: 제거 명세 검증 완료
**입력**: Ctrl+O 기능은 제거해줘.

## 사용자 시나리오와 검증

### 사용자 이야기 1 — 정리 기능 제거 (우선순위 P1)

개발자는 방금 추가한 Ctrl+O 미사용 import 정리 기능을 제거한다.
독립 검증: 플러그인의 정리 액션·단축키·우선순위 등록이 없고 배포물에도 구현 클래스가 없는지 확인한다.

1. Ctrl+O를 미사용 import 정리에 연결하지 않는다.
2. 액션 검색에도 JSP 미사용 import 정리를 제공하지 않는다.
3. 정리 전용 코드·테스트·include 메타데이터를 제거한다.

### 사용자 이야기 2 — 기존 편집 유지 (우선순위 P1)

개발자는 Java import 자동 추가와 기존 JSP 편집 기능을 계속 사용한다.
독립 검증: 기존 완성·빠른 수정·include·이동·포매팅 테스트를 실행한다.

1. 클래스 완성과 Alt+Enter import 추가가 유지된다.
2. 기존 include 해석과 다른 편집 기능이 유지된다.

### 경계 사례

- 사용자가 따로 지정한 IDE 키맵은 수정하지 않는다.
- 제거 전 명세·검증 기록은 폐기된 기능의 이력으로만 남긴다.

## 요구사항

- **FR-002**: 정리에서만 사용한 include 완전성·방문 파일 정보를 제거해 기존 구조를 복원한다.
- **FR-003**: README에서 정리 기능 안내를 제거하고 Java import 자동 추가를 보존한다.
