# 기능 명세: JSP 자바 편집 지원

**작성일**: 2026-10-20
**상태**: 검토 완료
**입력**: 기존 자바 에디터 기능을 재활용하여 JSP의 자바 자동완성, 포매팅, 구문강조를 제공한다.
**브랜치**: 저장소 메타데이터가 없는 작업 디렉터리에서 진행한다.

## 사용자 시나리오와 검증

### 사용자 이야기 1 — 자바 자동완성 (우선순위: P1)

개발자는 스크립틀릿·표현식·선언에서 기존 자바 편집과 같은 완성 후보를 얻는다.
우선 이유: 자바 코드를 직접 작성하는 핵심 흐름이다.
독립 검증: 문자열 변수와 선언 메서드의 완성을 실행하고 선택 결과를 확인한다.

1. 앞선 스크립틀릿에서 선언한 변수를 뒤의 표현식에서 사용할 수 있다.
2. HTML 사이에서 열린 조건문을 뒤 스크립틀릿에서 닫아도 같은 자바 문맥을 유지한다.
3. 페이지 import와 프로젝트 클래스, 선언 메서드 및 내장 객체의 타입을 완성에 사용한다.

### 사용자 이야기 2 — 자바 구문강조 (우선순위: P1)

개발자는 자바 키워드·문자열·주석을 자바 색상 설정으로 구분한다.
우선 이유: 코드 판독에 필요하다.
독립 검증: 세 자바 구문 종류에서 토큰별 강조와 JSP 구분자 보존을 확인한다.

1. 자바 본문은 자바 문법으로 강조하고 JSP 구분자는 기존 강조를 유지한다.
2. HTML·JS·CSS·EL·JSP 주석 및 지시자의 기존 처리는 유지한다.

### 사용자 이야기 3 — 자바 포매팅 (우선순위: P1)

개발자는 파일 또는 선택 영역 재정렬 시 자바 코드 스타일을 적용한다.
우선 이유: 요청한 세 편집 기능의 하나다.
독립 검증: 연산자 간격과 블록 들여쓰기, 반복 실행 및 선택 외부 보존을 확인한다.

1. 스크립틀릿·표현식·선언의 자바 공백을 재정렬한다.
2. JSP 구분자·HTML 내용·문자열과 주석의 의미를 보존하며 반복 실행 결과가 같다.

### 경계 사례

- 닫히지 않은 자바 구문은 편집을 계속할 수 있고 텍스트가 사라지지 않는다.
- 빈 자바 영역과 한글 문자열, 여러 줄 코드 및 HTML 속성 안 표현식을 처리한다.
- 서블릿 API가 프로젝트에 없으면 내장 객체의 해당 타입은 미해결 상태를 허용한다.
- javax 및 jakarta 서블릿 프로젝트를 지원하며 존재하는 API를 우선한다.

## 요구사항

### 기능 요구사항

- **FR-001**: 세 자바 영역에서 기존 자바 자동완성 기능을 제공해야 한다.
- **FR-002**: 여러 조각의 지역 변수와 제어문 문맥, 선언 멤버 및 page import를 공유해야 한다.
- **FR-003**: request, response, session, application, config, pageContext, out, page의 타입 문맥을 제공해야 한다.
- **FR-004**: 자바 본문은 자바 색상 설정을 따르고 구분자와 다른 언어의 강조는 유지해야 한다.
- **FR-005**: 자바 코드 스타일에 따라 본문을 재정렬하고 선택 외부와 비자바 영역을 보존해야 한다.
- **FR-006**: 미완성·빈 영역에서도 원문 손실과 예외가 없어야 한다.
- **FR-007**: 기존 웹 편집 기능의 회귀 검증과 신규 기능 통합 검증을 제공해야 한다.

### 주요 개체

- 자바 영역: 종류, 원문 위치, 구분자를 제외한 본문 범위를 가진다.
- 페이지 문맥: import, 선언, 순서가 있는 실행 코드와 내장 객체로 구성한다.

## 성공 기준

- **SC-001**: 세 종류 자바 영역의 완성 및 강조 시나리오가 모두 통과한다.
- **SC-002**: 분리된 제어문과 변수 공유, import 시나리오가 모두 통과한다.
- **SC-003**: 재정렬 후 의미 있는 문자와 선택 외부가 보존되고 두 번째 실행 결과가 동일하다.
- **SC-004**: 기존 웹 편집 테스트와 신규 자바 통합 테스트에 실패가 없다.

## 가정

- 기존 대상 IntelliJ IDEA 2026.1 계열과 설치된 Java 지원을 사용한다.
- EL 자체의 타입 추론, JSP include 통합 및 서블릿 코드 생성은 범위 밖이다.
- 파일 내부 선언 및 실행 코드의 문맥을 제공하며 실제 JSP 실행은 수행하지 않는다.

## 명확화 검토

2026-10-20: 앞선 대화에서 사용자가 세 기능과 자바 엔진 재사용을 승인했다. 범위·오류 처리·외부 의존성·완료 조건을 검토했으며 추가로 질문할 중대한 모호성은 없다.
