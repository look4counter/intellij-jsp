# 데이터 모델

## 자바 호스트

종류는 스크립틀릿·표현식·선언이다. 복합 노드 내부에 기존 렉서 토큰을 보존한다. 본문은 시작 구분자 뒤부터 종료 구분자 전까지이며 미완성 구문은 파일 끝까지다.

## 페이지 문맥

import 목록과 순서가 있는 호스트 목록을 가진다. 선언들은 하나의 클래스 본문 주입으로 연결한다. 실행 조각과 표현식은 별도 가상 클래스의 한 메서드에 연결하고 선언 사본을 클래스 멤버로 제공한다. 모든 실제 호스트 범위는 원문 순서를 유지한다. 가상 코드는 원문에 저장하지 않는다.

## 내장 객체

request·response·session·application·config·pageContext·out의 타입은 프로젝트의 서블릿 API를 따른다. page는 Object다. jakarta가 존재하면 우선 사용한다.
