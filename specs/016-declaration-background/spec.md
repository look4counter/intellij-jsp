# 기능 명세: JSP 함수 정의 영역 배경색 제거

**작성일**: 2026-10-21 | **상태**: 확정
**사용자 요청**: JSP 함수 정의 영역에 배경색이 적용된다면 제거한다.

## 사용자 시나리오와 검증

### 사용자 이야기 1: 자연스러운 함수 정의 표시 (우선순위: P1)

개발자는 `<%! ... %>` 선언부에 함수를 작성할 때 주변 편집기와 같은 배경에서 코드를 읽는다. 영역 전체의 별도 배경 강조를 제거하는 것이 목적이다.

**독립 검증**: 함수를 포함한 선언부를 열어 별도 영역 배경이 없는지 확인한다.

**인수 시나리오**:

1. 밝은 테마와 어두운 테마에서 선언부 본문에 주입 영역 배경색을 추가하지 않는다.
2. 여러 선언부와 필드 선언, 빈 선언부, 종료되지 않은 선언부에도 같은 정책을 적용한다.
3. 함수의 Java 구문 색상, 완성, 탐색, 포매팅은 유지한다.
4. 스크립틀릿과 표현식 및 다른 파일의 주입 영역 배경 정책은 유지한다.

### 경계 조건

선언부 텍스트를 변경하거나 갱신한 뒤에도 배경 정책을 유지한다. 선택 영역·검색 결과·오류 표시의 배경색은 이번 요청 범위에 포함하지 않는다.

## 요구사항

- **FR-001**: 선언부 본문에 별도 주입 영역 배경을 적용하지 않는다.
- **FR-002**: 선언부의 Java 편집 기능과 원문을 보존한다.
- **FR-003**: 선언부 이외 영역의 색상 정책과 사용자 전역 설정을 변경하지 않는다.

## 성공 기준

- **SC-001**: 함수·필드·복수·빈·미완성 선언부 모두 별도 주입 배경이 없다.
- **SC-002**: 기존 Java 편집 및 포매팅 검증이 모두 통과한다.
- **SC-003**: 스크립틀릿과 표현식의 배경 정책 변경 건수가 0건이다.

## 가정

함수 정의 영역은 JSP 선언부 `<%! ... %>`를 뜻한다. 함수 외 필드가 함께 들어갈 수 있으므로 선언부 전체에 동일한 정책을 적용한다. 기존 IntelliJ 색상 테마를 존중한다.

## 명확화 검토

범위·용어·사용자 흐름·경계 조건·검증 기준을 검토했다. 추가 질문이 필요한 중대한 모호성은 없다. 데이터 저장, 외부 서비스, 권한 및 새 설정은 필요하지 않다.
