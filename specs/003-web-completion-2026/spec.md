# 기능 명세: IntelliJ IDEA 2026.1 JSP 웹 자동완성

**작성일**: 2026-10-19
**상태**: 명세 확정
**브랜치**: 없음(현재 폴더는 Git 저장소가 아님)
**요청**: 무료 웹 자동완성을 재사용할 수 있도록 2026.1 버전에 맞게 만든다.

## 사용자 시나리오와 검증

### 사용자 이야기 1: 2026.1에서 기존 JSP 편집 (우선순위 P1)

개발자는 IntelliJ IDEA 2026.1에 플러그인을 설치하고 기존 JSP를 열어 강조·편집·저장한다.
우선 이유: 대상 버전에서 설치와 기존 기능이 동작해야 한다.
독립 검증: 2026.1 SDK로 빌드하고 기존 강조 및 문서 편집 테스트를 실행한다.

1. 2026.1 계열에서 플러그인을 설치할 수 있다.
2. JSP 파일 연결, 구문 강조, 한글과 원문 편집·저장 동작을 유지한다.

### 사용자 이야기 2: HTML 자동완성 (우선순위 P1)

개발자는 JSP의 HTML 부분에서 기본 태그·속성 자동완성을 사용한다.
우선 이유: JSP 작성에 가장 기본적인 보조 기능이다.
독립 검증: JSP에서 HTML 태그·속성 완성을 호출하고 후보 선택 후 원문을 확인한다.

1. `<di`에서 기본 HTML 후보 `div`가 나타난다.
2. 태그의 `cl` 속성 위치에서 `class`가 나타난다.
3. 앞뒤에 JSP 지시자·주석·표현식이 있어도 후보가 나타나고 선택한 텍스트만 해당 위치에 삽입된다.

### 사용자 이야기 3: JS·CSS 자동완성 (우선순위 P2)

개발자는 JSP의 script·style 영역에서 활성화된 기존 웹 언어 자동완성을 사용한다.
우선 이유: JSP에 함께 작성하는 웹 코드 편집을 지원한다.
독립 검증: script의 지역 변수와 style의 CSS 속성 후보를 확인하고 선택한다.

1. script에서 선언한 지역 변수 이름의 접두어로 해당 변수 후보가 나타난다.
2. style에서 `col`을 입력하면 CSS 속성 `color`가 나타난다.
3. JSP 구문이 앞에 있거나 해당 영역 안에 섞여 있어도 이후 위치의 완성 후보와 삽입 위치가 맞는다.

### 경계 조건

- 빈 파일과 미완성 JSP에서도 편집과 자동완성 요청이 예외 없이 동작한다.
- JSP 내부 Java 코드나 EL에 HTML 후보를 잘못 적용하지 않는다.
- 자동완성 결과를 선택해도 주변 JSP 구문, 한글 및 파일 내용을 훼손하지 않는다.
- 웹 언어 지원이 비활성화된 경우 해당 언어의 자동완성은 제공하지 않으며 HTML·JSP 편집은 유지한다.
- 기존 사용자 파일 연결을 강제로 바꾸지 않는다.

## 요구사항

- **FR-001**: 빌드 및 최소 지원 버전을 IntelliJ IDEA 2026.1 계열로 맞춰야 한다.
- **FR-002**: 기존 JSP 파일 연결, 구문 강조와 기본 편집·저장을 유지해야 한다.
- **FR-003**: HTML 영역의 태그·속성 자동완성은 IDE의 기존 기능을 재사용해야 한다.
- **FR-004**: 활성화된 JS·CSS 지원으로 script 지역 변수와 style 속성 자동완성을 재사용해야 한다.
- **FR-005**: JSP가 섞여 있어도 자동완성 위치를 원본 JSP 위치에 맞추고 선택한 후보 외 원문을 보존해야 한다.
- **FR-006**: 미완성 구문에서 안정적으로 동작하고 JSP 내부에 웹 자동완성을 잘못 적용하지 않아야 한다.
- **FR-007**: 웹 기능이 비활성화되어도 HTML·JSP 편집을 유지하고 웹 플러그인을 필수 설치 조건으로 만들지 않아야 한다.

### 주요 개체

- JSP 문서: 원문과 사용자 커서·선택 위치를 가진다.
- HTML 및 내부 웹 언어 영역: 원문 위치와 연결되는 편집 대상이다.
- 자동완성 후보: 기존 언어 기능이 제공하는 후보와 삽입 동작이다.

## 성공 기준

- **SC-001**: 2026.1 SDK에서 빌드·플러그인 구성 검사와 기존 강조 테스트가 모두 통과한다.
- **SC-002**: HTML 태그·속성, JS 지역 변수, CSS 속성의 대표 자동완성 사례 4종이 모두 성공한다.
- **SC-003**: JSP 전후 및 혼합 영역의 완성 선택 과정에서 원문의 의도하지 않은 변경이 없다.
- **SC-004**: 빈 문서·미완성 JSP·JSP 내부의 요청을 예외 없이 처리한다.

## 가정과 범위

- 설치된 2026.1.3을 검증 기준으로 삼는다. 최소 지원 계열은 2026.1이다.
- 앞선 대화의 자동완성 재사용 요청을 포함한다. 버전 번호 변경만 하는 작업이 아니다.
- HTML·JS·CSS 기본 자동완성에 집중한다. JSP Java·EL·태그 라이브러리 완성, 실행, 프레임워크 전용 완성은 포함하지 않는다.
- 사용 가능한 기존 언어 기능에 위임한다. 후보 목록을 별도로 하드코딩하지 않는다.
- 구문 연결, 완성 후보와 실제 삽입, 기존 강조 회귀를 자동 검증한다. 실제 IDE 창의 수동 확인 여부는 구분해 기록한다.

## 명확화 검토
