# 편집 계약

1. 클래스 완성은 기존 후보를 사용하고 단순 이름 또는 충돌 없는 완전한 이름을 삽입한다.
2. 필요한 import는 `<%@ page import="패키지.클래스" %>`로 현재 파일 앞부분에 추가하며 기존 원문을 보존한다.
3. 빠른 수정은 `JSP import 추가: 패키지.클래스`로 후보를 구분한다.
4. 명시적·와일드카드·include·java.lang으로 정확히 해석되는 클래스에는 지시자를 추가하지 않는다.
5. 충돌 시 기존 참조 해석을 유지하도록 완전한 이름을 사용한다.
6. 현재 파일만 변경하며 실행 취소·커서를 보존한다. HTML·EL·문자열·주석에는 후보를 제공하지 않는다.
